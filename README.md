# BillOS Cloud — Interactive Presentation

Static frontend only. No Supabase/backend connection is required.

## Start
Open `index.html` in a browser.

## Flow
index → Problem → Solution → Dashboard → Billing → Inventory → Bills → Analytics → Roles → Cloud → Vision

Every phase is a separate HTML page and the bottom navigation contains Back/Next controls.

## Included
- Premium dark/glass BillOS-inspired presentation UI
- Responsive mobile/desktop layout
- Light/dark theme toggle
- Interactive demo billing cart
- Interactive bills/receipt selector
- Interactive inventory row demo
- No backend / no build step
